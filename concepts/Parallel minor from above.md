# Parallel minor from above

Parallel minor from above is a chord substitution technique where a minor 7 chord is approached from a half step above using the same minor 7 chord type. For a target chord like G minor 7, this substitution places an Ab minor 7 immediately before it. This approach is simpler and more direct than some other substitution methods because it does not change the chord type—it merely uses the parallel minor chord from above as an approach voicing. The result is a slick, sophisticated harmonic movement that sounds beautiful and works whenever one is approaching any minor 7 chord. Unlike the tritone substitution, which uses a dominant chord, the parallel minor from above maintains the minor quality and creates a smooth chromatic descent into the target chord. This substitution emphasizes the beauty of harmonic color over theoretical complexity.
