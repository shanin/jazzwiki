# Sixth Diminished Scale

The sixth diminished scale, popularized by Barry Harris, is a symmetric scale pattern that alternates whole and half steps. It is particularly useful for generating harmonic color and altered chord tones in jazz contexts. The scale's inherent symmetry makes it invaluable for exploring voicing options and harmonic extensions. Musicians can borrow notes from adjacent sixth diminished patterns to create sophisticated alterations and counter-harmonic movement.
