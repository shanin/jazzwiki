# Magic Voicings

Magic voicings are sophisticated rootless comping voicings built on pentatonic scale foundations, designed for use in bands, big bands, and orchestral settings where the pianist accompanies without voicing the root. These voicings are characterized by minimal repeated notes and upper-structure extensions (altered ninths, sharp elevenths, thirteenths) that create crisp, cutting textures. The pentatonic scale base allows voicings to be transposed and moved within the same key center, generating varied colors while maintaining harmonic clarity.
