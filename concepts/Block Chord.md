# Block Chord

Block Chord refers to a voicing approach where all notes of a chord are stacked together in compact form, creating a unified harmonic block. This technique is the foundational concept for both Locked Hands and Drop Two voicing systems. Block chords emphasize harmonic clarity and can be applied melodically, allowing melodies to be played through the voicing structures themselves. Red Garland's famous approach to block chords on the Miles Davis recording exemplifies how these static left-hand voicings create a harmonic anchor while the right hand delivers melodic content.
