# Parallel minor from below

Parallel minor from below is a chord substitution where a minor 7 chord is approached from a tritone below the target chord. For a target chord like G minor 7, this substitution uses an F sharp-based chord that is a tritone away (below G). This approach creates one of the most beautiful and sophisticated harmonic movements, particularly effective in solo piano and trio contexts. The tritone interval creates ambiguity and tension that resolves elegantly into the target chord. However, this substitution is noted as requiring musicians in the band to have "very big ears" if it is introduced without prior warning, as the harmonic distance is significant. In appropriate settings, the parallel minor from below delivers a gorgeous and memorable harmonic color that stands out among common substitution techniques.
