# Locked Hands

Locked Hands voicing (also called Shearing Style or Block Chord) is a five-note voicing system where the top note of a four-way close chord is doubled an octave below in the left hand. This creates a characteristic octave-based structure where the melody note appears simultaneously in both hands, producing a rich, blocky harmonic sound. The octave relationship between the outer voices is the defining feature that distinguishes it from other voicing systems like Drop Two.
