# What Are Block Chords?

**Presenter:** Adam Maness | **Channel:** Open Studio
**Duration:** 7:32 | **YouTube:** [▶ Watch](https://www.youtube.com/watch?v=EQJj3hgzTkQ)

## Overview

An introduction to block chord voicing systems, specifically Locked Hands and Drop Two voicings. The instructor explains the foundational concepts, parent voicing structures, and practical applications of both systems across six jazz standards. The goal is to understand how to build and apply these voicings melodically in real tunes.

## Concepts Introduced

- [[Block Chord]] — fundamental voicing technique using stacked chords
- [[Locked Hands]] — five-note octave-based block chord system
- [[Drop Two]] — four-note tenths-based voicing derived from closed structures
- [[Four-way Close]] — foundational four-note closed voicing parent structure
- Shearing Style — alternative name for Locked Hands voicing

## Practice Notes

The video uses a simple D-flat minor 7 chord progression as a practical demonstration. The instructor loops the progression multiple times to allow for following along. Key practice points:
- Understanding how Locked Hands doubles the top note of a four-way close voicing an octave below
- Recognizing how Drop Two removes the second voice from the top and drops it an octave
- Hearing the sonic difference between octave-based (Locked Hands) and tenth-based (Drop Two) voicing systems

### [2:42] Four-way Close Foundation — [▶](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=162s)

[2:42](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=162s) Before developing either voicing system, understanding [[Four-way Close]] voicing is essential. This is the parent voicing structure for both [[Locked Hands]] and [[Drop Two]]. [[Four-way Close]] is a four-note voicing created by stacking all notes of a given chord in block chord fashion, such as a C major six chord containing C, E, G, and A arranged from bottom to top as E, G, A, C.

[3:20](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=200s) This foundational structure provides the starting point for developing both more complex voicing systems.

### [3:27] Building Locked Hands from Four-way Close — [▶](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=207s)

[3:27](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=207s) The [[Locked Hands]] voicing is created by taking the four-note [[Four-way Close]] structure and doubling the top note an octave below in the left hand. This produces a five-note voicing where the melody note appears in both the right hand and an octave lower in the left hand, creating the characteristic locked hands effect.

[3:39](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=218s) The definition is consistent: take any [[Four-way Close]] voicing and add the top note an octave below to create the [[Locked Hands]] structure.

### [3:56] Building Drop Two from Four-way Close — [▶](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=235s)

[3:56](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=235s) [[Drop Two]] voicing is created differently. Starting with a [[Four-way Close]] voicing, the second note from the top (in the C major six example, the A) is removed from the upper positions and dropped down an octave into the left hand. The voicing remains four notes, but the middle voice is displaced downward, creating a tenth-based interval structure.

[4:07](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=248s) The fundamental difference is simple: while [[Locked Hands]] adds a fifth note by doubling the top note, [[Drop Two]] maintains four notes by moving the second voice from the top down an octave.

[4:31](https://www.youtube.com/watch?v=EQJj3hgzTkQ&t=271s) Once the fundamental difference between [[Locked Hands]] and [[Drop Two]] is understood, the two systems become cousins in the voicing arsenal.
