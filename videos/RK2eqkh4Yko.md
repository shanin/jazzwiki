# How To Play Tunes Using Small Chords

**Presenter:** Adam Maness | **Channel:** Open Studio
**Duration:** 48:53 | **YouTube:** [▶ Watch](https://www.youtube.com/watch?v=RK2eqkh4Yko)

## Overview

This session demonstrates practical applications of small (six) chord voicings on real jazz standards. Moving beyond exercises, the instructor shows how to use closed and open voicings, with the melody as either the top of the chord or nestled between the root and melody note. The session emphasizes voice leading benefits and demonstrates four voicing approaches through detailed analysis of All the Things You Are, with live Q&A throughout to address student misconceptions.

## Concepts Introduced

- [[Closed Voicings]] — voicing structure where the melody is the top note of the chord and all voices are packed closely together
- [[Drop Two]] — voicing where the melody remains on top but the second note from the top is dropped an octave into the lower hand, creating spacious elegance
- [[Voice Leading]] — the principle of efficient, singable connections between chords; demonstrated through the four voicing approaches and their combinations

## Practice Notes

The session covers four primary voicing approaches, all using the same underlying six-chord shapes:

1. **Closed with melody on top**: Pack all notes tightly together with melody as the highest note
2. **Open (drop two) with melody on top**: Drop the second note from the top down an octave while keeping melody on top
3. **Closed with chord between root and melody**: Place a closed six-chord voicing between the bass note (root) and the melody note above
4. **Open (drop two) with chord between root and melody**: Use drop two spacing for the middle voicing between root and melody

All four approaches work within a two-hand framework and can be mixed within the same bar for textural and voice-leading variety. Non-chord tones in the melody can be accommodated by borrowing from the closest six-chord shape and substituting the non-harmonic tone.
